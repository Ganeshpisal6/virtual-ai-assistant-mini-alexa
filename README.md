# Virtual AI Assistant (Mini Alexa)

## Nexbridge Technologies - AI Internship Program

### Project 1: Virtual AI Assistant

A beginner-friendly, text-based virtual AI assistant built using Python.
The assistant runs completely offline in the terminal and uses rule-based
logic, keyword matching, and simple Python functions.

---

## 1. Project Objective

The objective of this project is to build a console-based virtual assistant
that can understand simple text commands and respond to the user.

The project demonstrates:

- Python programming fundamentals
- Functions
- Conditional statements
- Loops
- Exception handling
- Rule-based AI
- Basic ML concepts
- Basic DL/neural-network concepts

---

## 2. Features

The assistant supports the following features:

1. User name and personalized greeting
2. Current date
3. Current time
4. Basic calculator
5. Random motivational quote
6. Random joke
7. Random fact
8. Number guessing game
9. Help menu
10. Exit/quit commands
11. Friendly fallback for unknown commands
12. Rule-based recommendation demo
13. Simplified perceptron demo

---

## 3. Technologies Used

- Python 3.x
- VS Code
- Python Standard Library
- Terminal / PowerShell

### Python Modules Used

- `datetime`
- `random`

No external AI or ML frameworks are required.
